⚙️ API Server (Admin)

Nhập URL Cloudflare Worker để dùng server mode. Để trống = localStorage.

GET <server>/api/check-ip/<ip>?token=admin

Trả về: {"authorized": true/false}

import requests
def is_authorized(ip):
    r = requests.get(f"https://your-worker/api/check-ip/{ip}", params={"token":"admin"}, timeout=5)
    return r.json().get("authorized", False)

Tạo key

Nhấn nút để tạo key mới. Key sẽ được tự động rút gọn link và hiển thị bên phải.

Key & Link đã tạo

Copy link rút gọn và gửi cho người dùng. Họ mở link → vào tab Cấp phép IP → nhập key.

Chưa có key nào. Nhấn "Tạo key" để bắt đầu.

Cấp phép IP cho Proxy

Nhập key bạn nhận được → IP máy bạn được ghi nhận → proxy cho phép IP này kết nối.
