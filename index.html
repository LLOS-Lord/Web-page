API Check IP (cho Proxy)

Đây là API để máy proxy (máy khác) gọi kiểm tra IP đã cấp phép chưa. Không check trên web.

GET <server>/api/check-ip/<ip>?token=<admin_token> 
import requests

def is_authorized(client_ip):
    url = "https://your-worker.workers.dev"
    resp = requests.get(
        f"{url}/api/check-ip/{client_ip}",
        params={"token": "admin"},
        timeout=5
    )
    return resp.json().get("authorized", False)
